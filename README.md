# Django User Management CRUD App

A simple, lightweight **User Management system** built using Django's built-in User models and function-based views. This project implements full **CRUD** (Create, Read, Update, Delete) capabilities for handling user profiles.

## 🚀 Features Implemented
* **Create:** Add new users securely using Django's built-in forms.
* **Read:** Display all registered users in a clean HTML data table.
* **Update:** Edit existing user details (Username, Email, First Name, Last Name).
* **Delete:** Permanently remove user entries with a safety confirmation prompt.

## 🛠️ Tech Stack
* Python
* Django
* SQLite (Local database)
* Git / GitHub
